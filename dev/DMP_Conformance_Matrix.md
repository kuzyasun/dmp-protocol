# DMP conformance matrix

This evidence index separates scaffold/fixture results from provider and endpoint
conformance. P03 expands required cases into the canonical [137-row ledger](DMP_Normative_Cases.md)
([JSON](DMP_Normative_Cases.json)): planned test IDs, expected outcomes, owning
packages, independent-peer/interoperability gates and explicit unsupported scope.
Implementation-case results started as `not-run`; P05/P06 now record scoped
primary results in the ledger. Configuration evidence and structural parsing
do not pass endpoint cases. Whole-row acceptance includes later peer/interop gates.
`pending` / `not run` never means passed or unsupported. The owner-approved
[implementation transition](evidence/implementation-transition-20260927/README.md)
changes acceptance ownership below, not any historical test outcome. P01A is
development feasibility, P01B the actual library adapter, P01C integrated target
qualification; P13/P15 own actual SEC-1 behavior. Full P01 remains open.

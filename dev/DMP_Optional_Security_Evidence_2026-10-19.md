## Implemented behavior

- Manifests explicitly select `NONE` or `SEC-1` in the single `DMP-test-manifest/1.1` contract. The selected revisions are Core 11, DIRECT-1/RADIO-1 5, SELECTIVE-32 2 and SAMPLE-1 3. Generated JSON schema, deployment fixtures and exact manifest digests were regenerated with repository tooling.
- NONE endpoint frames carry Core CRC32C; Stream R retains its outer CRC. Direct NONE origin frames carry CONTEXT and ORIGIN_ID; routed NONE frames carry CONTEXT and ROUTE. Plaintext reply references use the full identity tuple.
- NONE boot epochs can be generated through a caller-provided fallible randomness callback. A single sequence allocator is shared across identity contexts with the same local namespace, node and epoch. Incoming epochs do not replace configured contexts.
- NONE uses caller-provisioned peer capacity without the SEC-1 four-peer cap. SAMPLE-1 supports caller-provisioned peer storage and validates the supplied capacity. SEC-1's existing peer cap and implementation remain separate.
- Added the NONE-only `libdmp_none` / `libdmp_sample1_none` composition from shared production sources. The NONE build rejects SEC-1 policy, emits no Noise/provider/handshake object dependency, and has no SEC-1 handshake symbols in its linked probe.
- Corrected direct plaintext ORIGIN_ID TLV flags to the normative C/U setting after the production endpoint loopback exposed the mismatch.
